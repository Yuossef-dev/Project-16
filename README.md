# 🏆 Al-Fatateeh Sports Club Website

A responsive, modern web application designed for **Al-Fatateeh Sports Club**. The project features a sleek dark UI, custom grid layouts, dynamic hover animations, and a contact form interface.

---

## ✨ Features

- 🎨 **Modern Dark Theme:** Styled with a clean dark layout, sleek gradients, and subtle neon border accents[cite: 1].
- 📱 **Fully Responsive Design:** Custom media queries ensuring perfect display on desktop, tablets, and mobile devices[cite: 1].
- 🧭 **Fixed Glassmorphism Header:** Smooth navigation bar with dynamic active states and backdrop blur effects[cite: 1].
- 🎴 **Product / Card Showcase:** Responsive CSS Grid layout for cards featuring auto-fit columns[cite: 1].
- 💬 **Testimonials Section:** Clean card layout displaying user ratings and reviews.
- ✉️ **Contact Section & Form:** Includes contact information boxes, social links, and an interactive form layout.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and accessible markup[cite: 2].
- **CSS3:** Custom styles, CSS Grid, Flexbox, transitions, media queries, and glassmorphism styling[cite: 1].
